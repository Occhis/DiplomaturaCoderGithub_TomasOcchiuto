# Diplomatura Coder - Proyecto Git y GitHub

Repositorio base configurado para la práctica y entrega de control de versiones con Git y flujos de trabajo en GitHub, estructurado siguiendo buenas prácticas de desarrollo y Conventional Commits.

## Tecnologías Utilizadas

- **HTML5**
- **Git** y **GitHub**

## Instalación y Uso (Cómo empezar)

Para clonar y poner en marcha este proyecto en tu entorno local, seguí los siguientes pasos.:

1. ### Instalación y clonación

```bash
git clone https://github.com/Occhis/DiplomaturaCoderGithub_TomasOcchiuto.git
cd DiplomaturaCoderGithub_TomasOcchiuto
```
