# Diplomatura Coder - Proyecto Git y GitHub

Repositorio base configurado para la práctica y entrega de control de versiones con Git y flujos de trabajo en GitHub, estructurado siguiendo buenas prácticas de desarrollo y Conventional Commits.

## Tecnologías Utilizadas

- **HTML5**
- **Git** y **GitHub**


## Flujo de Trabajo Colaborativo (Feature Branching)
El proyecto ha sido desarrollado aplicando un flujo de trabajo profesional basado en ramas:
1. **Rama `main`**: Contiene la versión estable y final del proyecto.
2. **Ramas de características (Features)**: Se utilizó una rama independiente (`agregar-seccion-servicios`) para desarrollar las nuevas secciones del sitio sin afectar la rama principal.
3. **Pull Requests (PR)**: Los cambios fueron integrados a `main` a través de un Pull Request debidamente revisado y documentado.
